# water-quality-prediction

PyTorch-based experiments for predicting water potability using neural networks on the Water Potability dataset.

The project focuses on data preprocessing, leakage-free imputation, model architecture experiments, and evaluation.

Current MLP baseline: 68.60% accuracy and 0.6402 macro F1.

Built as a practice exercise in ML experimentation and model evaluation.

### File information
 	- MLP.ipynb: notebook with main project code, such as preprocessing, splitting data, mlp training, etc.
	- Model_comparisons.ipynb: notebook comparing project's trained mlp with logistic regression.


### Dataset used:
	- Water quality by MOBINA ROUDGAR: https://www.kaggle.com/datasets/mobinaroudgar/water-quality
